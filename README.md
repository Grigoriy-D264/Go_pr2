# Поиск максимального значения

Программа генерирует `SIZE = 100_000_000` положительных целых чисел
и ищет максимум двумя способами: последовательно и в `CHUNKS = 8` горутинах.
Для обоих способов используются одни и те же данные. Время поиска выводится
в микросекундах, без учёта генерации данных.

## Запуск

Нужен Go 1.24.1 или новее. В каталоге проекта выполните:

```sh
go run .
```

На 64-битной платформе слайс занимает примерно 800 МБ памяти.
Для небольшого эксперимента можно уменьшить `SIZE` в `main.go`.
Ускорение зависит от процессора, доступного параллелизма и памяти.

## Крайние случаи

- При размере не больше нуля генератор возвращает пустой слайс.
- Для пустого или `nil` слайса обе функции поиска возвращают `0`.
- Поиск поддерживает также отрицательные числа и не изменяет исходный слайс.
- В параллельном поиске последняя часть включает остаток от деления на 8.
  Пустые части не влияют на результат.

## Проверка

```sh
go test ./...
go vet ./...
```

Тесты проверяют генерацию положительных чисел, крайние значения `int`,
пустые, короткие и неполные слайсы, а также максимум в каждой позиции
слайсов разных размеров.
